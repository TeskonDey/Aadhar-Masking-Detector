# Aadhaar Masking Detector API

A FastAPI-based document verification service that accepts Aadhaar-related PDF and image documents, extracts text using OCR, and checks whether an Aadhaar number is properly masked.

## Features

- Upload PDF, JPEG, or PNG documents through an API endpoint.
- Convert PDF pages into high-resolution images using PyMuPDF.
- Process image uploads using OpenCV.
- Extract text using Tesseract OCR.
- Automatically fall back to EasyOCR when Tesseract produces insufficient text.
- Detect fully visible 12-digit Aadhaar numbers.
- Detect properly masked Aadhaar numbers.
- Ignore 16-digit Virtual ID (VID) values to reduce false positives.
- Return a structured compliance response.
- Log document processing and pipeline failures.

## How It Works

The API follows this pipeline:

```text
Document Upload
      ↓
File Type Validation
      ↓
PDF/Image Processing
      ↓
OCR Text Extraction
      ↓
VID Sanitization
      ↓
Aadhaar Pattern Detection
      ↓
Compliance Result
```

The FastAPI application connects the ingestion, OCR, and Aadhaar compliance modules into a single `/api/v1/verify-aadhaar` endpoint. fileciteturn1file3L5-L15

## Supported Files

The API accepts:

- PDF
- JPEG
- JPG
- PNG

Other file types return a `400 Bad Request` response. fileciteturn1file3L22-L29

## OCR Processing

For image documents, OpenCV decodes the uploaded bytes into an image. PDF documents are opened with PyMuPDF and each page is rendered at approximately 300 DPI before OCR processing. fileciteturn1file0L8-L14 fileciteturn1file0L19-L39

The OCR engine first uses Tesseract. If fewer than 10 valid alphanumeric characters are detected, EasyOCR is used as a fallback. fileciteturn1file1L13-L30

## Aadhaar Compliance Detection

Before checking Aadhaar patterns, the application replaces detected 16-digit VID values with `[VID]`. This prevents a VID from being incorrectly interpreted as an Aadhaar number. fileciteturn1file2L6-L15

The detector checks for:

### NON_COMPLIANT

A fully visible 12-digit Aadhaar number is detected.

```text
XXXX XXXX XXXX
```

where all twelve digits are visible.

### COMPLIANT

A masked Aadhaar pattern is detected, such as:

```text
XXXX XXXX 1234
```

The current implementation specifically checks for four masked characters, followed by four masked characters, followed by four digits. fileciteturn1file2L15-L24

### NOT_FOUND

No valid Aadhaar pattern is detected. fileciteturn1file2L22-L27

## API Endpoint

### Verify Aadhaar Document

```http
POST /api/v1/verify-aadhaar
```

Upload a document using the `file` form field.

Example using cURL:

```bash
curl -X POST "http://127.0.0.1:8000/api/v1/verify-aadhaar" ^
  -H "accept: application/json" ^
  -H "Content-Type: multipart/form-data" ^
  -F "file=@sample.pdf"
```

## Response Format

A successful request returns JSON similar to:

```json
{
  "filename": "sample.pdf",
  "status": "COMPLIANT",
  "details": "Masked Aadhaar format verified."
}
```

The response includes the uploaded filename, compliance status, and explanation generated by the pattern matcher. fileciteturn1file3L32-L39

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:


```bash
pip install -r requirements.txt
```

The project requirements include FastAPI, Uvicorn, python-multipart, OpenCV, Tesseract Python bindings, EasyOCR, PyMuPDF, and Pydantic. fileciteturn1file4L1-L8

## Tesseract OCR Requirement

`pytesseract` is used by the Python application, so the Tesseract OCR engine itself must also be installed and available on the system PATH.

Verify the installation with:

```bash
tesseract --version
```

If the command is not recognized, install Tesseract separately and configure its executable path if necessary.

## Running the API

Start the FastAPI application with Uvicorn:

```bash
uvicorn main:app --reload
```

The API will normally be available at:

```text
http://127.0.0.1:8000
```

FastAPI also provides interactive API documentation at:

```text
http://127.0.0.1:8000/docs
```

## Example Workflow

1. Start the FastAPI server.
2. Open `/docs`.
3. Select `POST /api/v1/verify-aadhaar`.
4. Upload a PDF, PNG, JPG, or JPEG.
5. Execute the request.
6. The service converts the document into images when required.
7. OCR extracts the text.
8. The pattern matcher sanitizes VIDs and checks Aadhaar patterns.
9. The API returns the compliance status.

## Error Handling

The application handles:

- Unsupported file formats with HTTP 400.
- Document-processing failures through logging.
- Unexpected pipeline failures with HTTP 500.
- Invalid image decoding.
- PDF processing errors.

The API returns a generic internal-server-error message for unexpected processing failures. fileciteturn1file3L41-L45

## Security Considerations

This project is intended for Aadhaar masking verification. When deploying it with real identity documents:

- Use HTTPS.
- Avoid storing uploaded documents unless necessary.
- Avoid logging sensitive OCR text.
- Restrict access to the API.
- Validate file sizes and content.
- Apply appropriate data-retention and privacy controls.
- Do not expose sensitive Aadhaar information in API responses or logs.
